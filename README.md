## Using the snippets

These files combine prose, numbered answers, and partial class or method definitions. They are study material, not standalone `.java` source files, and cannot be compiled together as a project.

To try a solution, copy the relevant snippet into an appropriately named Java class, add any required surrounding code and imports, then compile and test it separately.

There is no automated test suite. Answers may be incomplete or need correction; use them to compare approaches after attempting the problems yourself, and follow your course's rules on outside solutions.
